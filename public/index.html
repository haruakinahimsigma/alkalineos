A fresh boot.
From the ground up.

Alkaline OS is a learning project to build a bootable operating system, one milestone at a time. This site is its web companion — the kernel runs separately in an emulator.

View the source on GitHub →

⌁

Boot sector

First milestone: a 512-byte x86 BIOS boot sector that prints a startup message and halts.

Status: starter committed

⌘

Build it

Use a Linux workspace with NASM and QEMU, then run ./build.sh and boot the generated image.

↗

Next milestones

Second-stage loader, freestanding kernel, serial logging, memory management, interrupts, and eventually a shell.

Read the roadmap →

Alkaline OS is an experimental hobby project. This web page is not the operating system itself and does not boot or emulate the kernel. iPadOS remains untouched.
